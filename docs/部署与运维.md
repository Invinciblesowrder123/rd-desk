# 部署与运维

## 1. 环境

- Windows 10/11（`pmdesk.py` 里的进程枚举用了 Windows 的 PowerShell 路径；Linux/macOS 需自行改）
- Python 3.9+，**无第三方依赖**
- 端口 `8787`（可用命令行参数改）

---

## 2. 启动与停止

### 一键（推荐）

```
start-all.bat    起中台 + 飞书 bot，然后自动开浏览器
stop-all.bat     两个都停
```

### 命令行细粒度

```bash
python pmdesk.py status                 # 谁在跑、PID 多少
python pmdesk.py start center           # 只起中台
python pmdesk.py start bot              # 只起飞书监听
python pmdesk.py restart center         # 重启
python pmdesk.py stop bot --dry-run     # 只看会杀谁，不动手
```

组件：

| 名称 | 是什么 | 判定方式 |
|---|---|---|
| `center` | 中台服务（本仓库） | 端口 8787 的 `/api/rev` 能通 |
| `bot` | 飞书长连接（pmbot，可选） | 进程命令行含 `run_pmbot.py` + `feishu-ws` + `.env.prod` |
| `web` | pmbot 的网页聊天（可选） | 进程命令行含 `run_pmbot.py` + `serve` |

停止**不按进程名杀**，按命令行特征精确匹配，所以手工启动的实例也能收掉，
不会误伤机器上其他 python 进程。

### 只想起中台（不用 pmdesk）

```bash
cd local
python server.py 8787
```

---

## 3. 端口与访问

- 服务绑 `127.0.0.1`，只本机可访问。
- 页面地址 `http://127.0.0.1:8787/index.html`
- 换端口：`python local/server.py 8790`

要让同事用，需要改 `server.py` 里的绑定地址，并且**必须自己加鉴权**——
`/api` 是不带认证的写接口，暴露到局域网等于谁都能改数据。

---

## 4. 日志

`logs/center.log`、`logs/bot.log`（由 `pmdesk.py` 启动时写入），PID 记录在 `logs/pids.json`。

`server.py` 只在 `/api` 请求时打一行 `[api] GET /api/...`，静态请求不记，避免刷屏。

---

## 5. 备份与恢复

### 备份（推荐拷文件）

```bash
python pmdesk.py stop center
cp bridge/desk.db  backup/desk-$(date +%Y%m%d).db
cp bridge/desk.db-wal backup/ 2>/dev/null   # 有就一起拷
```

WAL 模式下的注意事项：**只拷 `.db` 不拷 `-wal` 会丢最近写入**。
稳妥做法是先停服务（SQLite 会把 WAL 合并回主文件），再拷。

### 备份（不拷文件）

```bash
curl --noproxy '*' http://127.0.0.1:8787/api/export > backup.json
```

拿到的是 `{projects, nodes, logs, reviews, rev, exportedAt}`，也是种子格式，可以直接当 `data/seed.json` 用。

### 恢复

页面「我的 → 从备份恢复」可以导入 JSON（会覆盖当前数据，有二次确认）。

命令行恢复：把 JSON 放成 `data/seed.json` → 停服务 → 删 `bridge/desk.db` → 启动。

## 6. 常见故障

**页面打开是空的 / 一直"读取失败"**

1. 是不是双击的 `index.html`？`file://` 下拿不到 `/api`，必须走 `http://127.0.0.1:8787/`。
2. 服务起了吗？`python pmdesk.py status`，或浏览器直接开 `/api/rev` 看有没有 JSON。

**端口被占**

```
netstat -ano | findstr :8787
taskkill /PID <pid> /F
```

**`/api/rev` 返回 502 或奇怪的错误**

机器上可能配了代理（`HTTP_PROXY`）。本地探测要绕开代理：命令行用
`curl --noproxy '*'`；Python 里用 `urllib.request.build_opener(urllib.request.ProxyHandler({}))`。

**启停脚本说"已在运行"但我没看到**

它按命令行匹配，可能是上次没退干净的实例。`python pmdesk.py status` 看 PID，
再 `python pmdesk.py stop center` 收掉。

**改完页面源码没生效**

`local/index.html` 是构建产物，改 `src/build/*` 之后要跑 `python src/build.py`。

---

## 7. 升级

```bash
git pull
python src/build.py        # 重新拼页面
python pmdesk.py restart center
```

数据库结构不用迁移：记录是整行 JSON，新字段对老数据就是"缺一个键"，读取时按空值处理。

---

## 8. 定时任务

本仓库不带调度。需要每天自动推日报的话，在 Windows 任务计划里挂一条：

```
程序：python
参数：pmdesk.py start
起始于：<仓库目录>
```

或者直接用 pmbot 自带的定时推送（见 docs/pmbot-接入.md）。
